🌸 Task 1:
 Iris Flower Classification

📌 Project Overview: 
Predicts the species of an iris flower (Setosa, Versicolor or Virginica) from its petal and sepal measurements.

🛠️ Tech Stack and Libraries:
 Python, Jupyter Notebook, pandas, NumPy, matplotlib, seaborn, scikit-learn

🔄 Workflow and Implementation:
 Load data → EDA → Pairplot and box plots → Feature selection → 80/20 train-test split → Train 4 models (Logistic Regression, KNN, Decision Tree, Random Forest) → Evaluate with accuracy, confusion matrix and classification report

📊 Model Performance: 
All models gave high accuracy. Petal length and petal width were the most important features, and the few errors were between Versicolor and Virginica.
